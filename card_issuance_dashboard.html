📖 대시보드 가이드

개요

본 대시보드는 신규 입회 고객의 전체 여정을 분석합니다. 도입신청서 제출부터 카드 발급, 첫 결제, 월별 한도 소진까지의 퍼널을 추적하여 병목 구간을 진단하고 운영 액션을 도출합니다.

Part A -- 신규입회 전환율

도입신청 -> 승인 -> 가입 -> 한도산출 -> 카드발급 -> 첫결제까지의 단계별 전환율을 분석합니다.

  • KPI 카드: 전체 전환율, 한도산출 유효율, 한도0원 비율, 첫결제 전환율
  • 퍼널 차트: 선택 기간 합산 단계별 건수 (수평 바)
  • 트렌드 차트: 월별 전환율 추이 (라인)
  • 월별 상세 테이블: 모든 단계의 월별 상세 수치

Part B -- 사용 유도 및 한도 소진율

카드 발급 후 실제 사용 활성화를 추적합니다. 코호트(발급월) 기준으로 M0~M3 소진율과 목표 달성률을 모니터링합니다.

  • KPI 카드: 첫결제율, M1(20%)/M2(35%)/M3(45%) 달성률 동시 표시
  • 사용 유도 퍼널: 카드발급 -> 첫결제 -> M1/M2/M3 달성 건수
  • 코호트 라인차트: 발급월별 M0~M3 평균 소진율 추이
  • 달성률 바 차트: 코호트별 M1/M2/M3 목표 달성 비율
  • 데이터 출처: mart_card.export_card_issuance_initial_usage

Part C -- 운영 액션 추천

데이터 기반 액션 아이템과 실험 가설을 제시합니다.

  • 세그먼트 분석: 한도 구간별 소진율, 업종별 M1 소진율
  • M1 달성/미달성 비교: 두 그룹의 특성 차이 분석
  • 가설 테이블: 우선순위별 운영 가설과 검증 방법

조회기간 필터

상단 필터바에서 기간을 선택하면 Part A는 신청월 기준, Part B는 발급월(코호트) 기준으로 필터링됩니다.

용어 정의

M0카드 발급 당월 소진율
M1발급 후 1개월차 소진율 (목표: 20% 이상)
M2발급 후 2개월차 소진율 (목표: 35% 이상)
M3발급 후 3개월차 소진율 (목표: 45% 이상)
달성률목표 소진율 달성 법인 수 / 전체 대상 법인 수
소진율실사용금액 / 부여한도 (normal_amount / normal_granted_limit)

          -- 발급 퍼널 집계 쿼리 (BigQuery) SELECT FORMAT_DATE('%Y-%m', submitted_at) AS month, COUNT(DISTINCT application_id) AS submitted, COUNT(DISTINCT CASE WHEN status = 'approved' THEN application_id END) AS approved, COUNT(DISTINCT CASE WHEN signup_at IS NOT NULL THEN user_id END) AS signup, COUNT(DISTINCT CASE WHEN limit_start_at IS NOT NULL THEN user_id END) AS limit_start, COUNT(DISTINCT CASE WHEN limit_progress_at IS NOT NULL THEN user_id END) AS limit_progress, COUNT(DISTINCT CASE WHEN limit_result_at IS NOT NULL THEN user_id END) AS limit_result_any, COUNT(DISTINCT CASE WHEN credit_limit > 0 THEN user_id END) AS limit_nonzero, COUNT(DISTINCT CASE WHEN credit_limit = 0 THEN user_id END) AS limit_zero, COUNT(DISTINCT CASE WHEN card_info_at IS NOT NULL THEN user_id END) AS card_info, COUNT(DISTINCT CASE WHEN card_apply_at IS NOT NULL THEN user_id END) AS card_applied, COUNT(DISTINCT CASE WHEN card_issued_at IS NOT NULL THEN user_id END) AS card_issued, COUNT(DISTINCT CASE WHEN first_spend_at IS NOT NULL THEN user_id END) AS first_spend FROM card_applications GROUP BY 1 ORDER BY 1;
