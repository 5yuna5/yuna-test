# 입회서류보완 자동 안내 메일 발송

## 개요

카드사 입회서류 보완요청 시, 고객에게 보완 필요 서류 안내 메일을 자동 발송하고 Google Drive 업로드 링크를 제공하는 운영 자동화 프로젝트.

## 배경

- 카드사(롯데/BC)에서 입회서류 보완을 요청하면 슬랙 채널(`bot-카드사-입회서류보완`)에 알림이 수신됨
- 현재 운영담당자가 수기로 고객에게 이메일을 보내 서류 보완을 안내하고 있음
- 건당 10~15분 소요, 하루 여러 건 발생 시 상당한 운영 시간이 소모됨
- 안내 누락/지연 시 입회 처리가 늦어져 고객 경험에 부정적 영향

## 목표

1. **운영 시간 절감**: 건당 수기 10~15분 → 자동화로 0분 (모니터링만)
2. **고객 응답 속도 향상**: 보완요청 후 1시간 이내 자동 안내 메일 발송
3. **서류 수집 편의성**: Google Drive 업로드 링크 제공으로 고객 서류 제출 간소화
